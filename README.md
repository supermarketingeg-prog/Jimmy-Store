# 👟 Jimmy Store | متجر الكوتشيات المستوردة ولوحة التحكم الذكية

متجر إلكتروني متكامل وعصري لبيع الكوتشيات الهاي كوبي والمستوردة والكروكس (Men | Women | Kids Sneakers & Crocs) في مصر، مزود بـ **لوحة تحكم كاملة للعميل / صاحب المتجر (Admin Panel)** لإدارة الأسعار، الصور، البانرات، واستقبال الطلبات عبر الواتساب.

---

## 🌟 مميزات المتجر للعميل النهائي:
1. **واجهة عربية أنيقة وسريعة جداً**: تصميم Dark Mode فخم ومتوافق مع الموبايل والكمبيوتر.
2. **أقسام متكاملة**: (رجالي 👟 | حريمي 👠 | أطفالي 👶 | كروكس 🔥 | عروض وتخفيضات 🏷️).
3. **اختيار المقاسات والألوان**: إمكانية اختيار المقاس المتاح (37-45) واللون والكمية.
4. **سلة مشتريات ذكية + إنهاء الطلب عبر الواتساب**: فورم بيانات العميل (الاسم، الموبايل، المحافظة، العنوان) يقوم بتجهيز رسالة واتساب منسقة تلقائياً بضغطة زر.
5. **معلومات الشحن والضمانات**: دعم الدفع عند الاستلام والمعاينة قبل الدفع لجميع محافظات مصر.

---

## 🎛️ مميزات لوحة التحكم الخاصة بصاحب المتجر (Admin Panel):

يمكن لصاحب المتجر الدخول للوحة التحكم بالضغط على **"دخول الإدارة"** أو أيقونة القفل:

- **🔐 تسجيل دخول آمن**: بكلمة مرور خاصة (الافتراضية: `admin` ويمكن تغييرها في أي وقت من الإعدادات).
- **👟 إدارة المنتجات والأسعار**:
  - إضافة كوتشي جديد بالاسم، السعر، السعر قبل الخصم، الوصف، والمقاسات.
  - تعديل الأسعار وتحديثها فورياً.
  - رفع صور من الموبايل أو الكمبيوتر أو وضع رابط صورة.
  - إخفاء أو إظهار المنتجات حسب التوفر في المخزن (متوفر / نفذت الكمية).
  - حذف أو تعديل أي منتج.
- **🖼️ تعديل البانر والإعلانات**:
  - تغيير عنوان وصورة البانر الرئيسي في الصفحة الأولى.
  - تفعيل أو إيقاف شريط الإعلانات المتحرك أعلى الصفحة وتعديل نصه.
- **📱 إعدادات الواتساب والتوصيل**:
  - تغيير رقم الواتساب الذي يستقبل الطلبات.
  - تحديد سعر مصاريف الشحن والحد الأدنى للشحن المجاني.
  - تغيير كلمة مرور لوحة التحكم.
- **🛒 سجل الطلبات**:
  - مشاهدة كافة الأوردرات التي تمت على الموقع مع بيانات كل عميل وزر للتواصل معه مباشرة على الواتساب.
- **💾 النسخ الاحتياطي**:
  - تصدير نسخة احتياطية من كافة المنتجات والأسعار بضغطة زر.

## 🚀 كيفية تشغيل المشروع محلياً:

```bash
# تثبيت الحزم
npm install

# تشغيل السيرفر المحلي للتطوير
npm run dev
```

## 🌐 كيفية الرفع على GitHub و Vercel:

لرفع الكود على المستودع الخاص بك على GitHub:

```bash
git add .
git commit -m "feat: complete Jimmy Store with client admin dashboard"
git branch -M main
git push -u origin main
```

بعد ذلك:
1. ادخل على حسابك في [Vercel](https://vercel.com).
2. اضغط على **"Add New Project"** واختر ريبو `supermarketingeg-prog/Jimmy-Store`.
3. اضغط **Deploy** وسيتم نشر الموقع في ثوانٍ مع رابط دائم ومجاني!
